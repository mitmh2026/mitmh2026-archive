    Solution to On the Fence

    Answer: CITY HALL
    Written by: Tim Miller
    Edited by: Herman Chau

    Having only numbers on cells indicates that we likely have some sort of logic puzzle, and the title points to Fences, AKA Slitherlink. Slitherlink rules:

    • The number on a cell represents how many edges must be used in the solution.
    • There is exactly one loop.

    In this set of puzzles, there are some cells with inequalities. We should assume that these inequalities need to be satisfied as well. Some trivial ideas that will help the solve path:

    • If there are N used edges on a cell with N, all of the rest of the edges must be unused.
    • If there are 6-N unused edges on a cell with N, all of the rest of the edges must be used.

    If a used edge can only connect to one other edge, that other edge must also be used. This can extend to a sequence of edges with only one possible exit–very useful on borders.

    Some nontrivial key ideas that will help the solve path:

    • For any vertex, the number of edges that may come out from it is either two or zero. If one edge coming into a vertex is used, exactly one of the other two edges must be used. If two edges coming into a vertex are unused, the third must also be unused.
    • A 3 cell that has three consecutive edges on the boundary of a region will need to use the edge extending out of that cell, continuing said edge sequence. The following images illustrate this deduction.

    These ideas should be able to take solvers through most of the regions. Solution images are below.
