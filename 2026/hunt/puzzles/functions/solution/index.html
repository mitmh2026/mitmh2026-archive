    Solution to Functions

    Answer: DRASTIC
    Written by: Dan Simon

    At first glance, it may be unclear where to start on this puzzle. There's a fairly standard (British-style, i.e. with many unchecked letters) grid, but the "clues" are all expressions using the functions a, b, c, d, e, f, and g, question marks, and a few free letters. (For example, one of the clues, 5-Across, is g(a(?), P).) There's also a list of words and a list of more normal-looking (but very vague) clues below the puzzle, with both lists alphabetized, and lists of seven more function expressions and ten clue locations (e.g., "1-Down") even further down.

    There are 51 total question marks in the function expression "clues" (not counting those in the bottom list of seven function expressions), and 51 words in the list of words. There are also 30 function expression "clues" (the clue numbering only goes up to 27, but three numbers are used for both Across and Down) and 30 clues in the list of more normal-looking clues. From this, solvers might guess at this very rough solving process:

    • The question marks are replaced by the 51 words, using each word once.
    • The function expression "clues" can then be evaluated.
    • The answer to each function expression "clue" matches one of the 30 vague normal clues, using each once.
    • The answer to each clue is put in the grid in the appropriate place, as in a normal crossword.

    Of course, it's also entirely possible for solver to consider some aspects of the above before counting the numbers of clues/question marks/list items, and then confirm by counting them.

    However, to actually start solving clues, solvers will need to determine what (at least some of) the functions are. Looking at the functions and the word list more closely, there are several more things solvers might notice:

    • Throughout the puzzle, a, b, c, and e always only have one parameter, d and f have two parameters, and g has two or three parameters, which reduces options for what each function could be.
    • The fact that the grid is British-style, the fact that definitions are given (albeit likely out of order), and the many short words in the list of words may cause solvers to think the functions are letter manipulation/cryptic-style "wordplay", rather than being based on word meanings.
    • Some of the relatively longer words in the wordlist, e.g. CATALOG and MILLION, have other words in the wordlist that are substrings of them, here CAT and MILL, which might suggest a removal function.
    • Every function is used at least twice without any nesting (g, which is generally used a lot, is used more than twice without nesting). In most of these cases, all parameters are ?, though 6-Down g(?, ?, S) and 12-Down d(?, N) are exceptions. This means every function has some relatively simple starting points, rather than, for example, solvers having to use 14-Down d(g(?, D), b(c(?))) to start the puzzle.
    • The grid gives the length of each function expression "clue" answer, as in a normal crossword. (However, unlike in most cryptic crosswords, the enumerations are not given on clues.) This narrows things down somewhat.
    • Though the normal-looking clues are very vague, trying to guess at the several most plausible options for each will give the intended answer for a few, which can help in finding transformations via trying to somehow make those answers from the given list of words. (This is somewhat less likely to work/higher effort than the other methods above, because solvers don't know if the clue answers they're trying to justify are in fact correct, and don't even have a length. But it becomes slightly stronger later on after narrowing things down.)

    As will be seen, the functions include some of the most common wordplay functions (e.g., concatenation and reversal), so if nothing else, enough trial and error should let solvers break in eventually.

    (Note: the single letters used as parameters in some function expression "clues" are just that letter, not variables or anything. This may not be immediately obvious, but should become clear at some point during the solve.)

    As with a normal crossword, filling some clue answers in gives some letters for other clues. However, unlike a normal crossword, solving clues also helps with other clues in that it lets solvers cross off some used items from the word/normal clue lists, creating fewer options for the remaining clues. Also, of course, being able to figure out any function helps with several clues (since there are only seven and they're each used at least four times). So, overall, after the initial breakin, filling in more clue answers should generally get easier, though of course since the "easier" clues get filled in first, this isn't strictly true.

    In any case, solvers should eventually be able to figure out all the functions, solve all the clues and fill out the grid. The functions are:

    FunctionFunction effect
    a(x)odd letters of x (every other letter, starting with the first)
    b(x)x without its last letter
    c(x)x without its first letter
    d(x, y)y inserted inside x
    e(x)reversal of x (letter-by-letter, not meaning)
    f(x, y)y removed from x
    g(x, y) or g(x, y, z)concatenation of x and y (and z if present)

    Some notes:

    • All these functions are strictly based on letters, not sound (e.g. homophone) or meaning (e.g. opposite).
    • Function d, unlike the others, is not well-defined; the insertion is not necessarily at the exact center, though there's always at least one letter before/after the insertion. However, the fact that the final output must be a word matching a given definition constrains it.
    • Wherever function f is used there is only one possible removal (so there's no difference between it removing all occurrences or just one).

    As for extraction, once solvers get the basic idea of how the main part of puzzle works (fill in the question marks, apply the functions, put the result in the grid), extraction should be fairly clear. The lists of seven more function expressions and ten clue locations at the very bottom of the puzzle have not yet been used. As it turns out, the seven function expressions have ten total question marks, which suggests substituting the answers to the ten given clues into the question marks.

    Actually making progress on extraction is harder, because there are no definitions. However, as solvers figure out functions and solve the given clues, they can start filling out the extraction section. (Note that the answers to the other 20 clues are not used for extraction; solving those clues only helps with getting checked letters/eliminating options/determining functions as described above.)     These result words are all, continuing the cryptic wordplay theme, cryptic letter indicators. They are mostly of different types, though CHARLIE and INDIA are both NATO letters. RUN and SHILLING are somewhat more obscure than the others; RUN is R due to sports, while the UK SHILLING used to be written as s.

    It is also possible to get the same letter by just taking the first letters of the result words.

    The functions a-g were given in order, but it is not necessary to reorder. (This is possible since the names a-g are arbitrary, so the function names were assigned so function name order was extraction order. The ten clues are also given in clue-number order, but these are reordered in replacing the question marks.)

    Taking either first letters or (equivalently) cryptic letter indicators using the order in the above table, we get the answer, DRASTIC.

    Author's Notes

    This is definitely not a very innovative puzzle, but testsolves generally found it enjoyable so it at least has that going for it. It was written in a fairly short time (mostly early one morning) to fill one of the last slots in its round.

    I think I wrote some code at one point attempting to show uniqueness (assuming things are used once and the functions are known) even without the list of 30 normal clues, just assuming the outputs are words. However, it seems clear a version of the puzzle without those clues where you have to assume you make words would be far too hard, both to break in to and to solve (if you have a transformation wrong, that could heavily mess things up). Having those clues also makes this both slightly more like a cryptic and slightly more of a word puzzle, as opposed to a coding puzzle.

    That being said, these 30 normal clues were basically the last part written. They were also the part that needed to be tweaked the most; thanks to testsolvers for suggesting some changes to a few of them to make them more fair.

    I think every testsolve of this puzzle only thought about extraction when they had at least 9/10 of the needed 10 entries. However, I think all testsolves were missing some/most of the bottom right, which is probably the section with the most complicated clues and which has only two (DIARY and ONES) of the ten extraction entries.

    Coincidentally, seven of the ten extraction entries in the grid are four letters long, and these are also all but one of the eight four-letter entries in the grid. (The excluded one is 22-Down, GNAT.) Hopefully extraction was clear enough that this didn't confuse any teams.

    Enumerations are not given on clues because talking to testers, it seemed the slight possible extra confusion from e.g. (7) seeming like another function call wasn't worth the slight quality-of-life benefit from not having to check the grid.

    The section of this blog post by Dan Katz (not me, for those who only read first names) about Analog Circuitry (MITMH 2021) and Transmogrifiers (MITMH 2007) was an inspiration for this puzzle. (Disclaimer: I am writing these author's notes months after writing the puzzle, and I may have stumbled across this blog post section after writing the puzzle; I'm not sure. It was an inspiration in spirit at least.) I think this puzzle takes "wordplay function blackbox puzzle" in another direction, albeit one (IMO) more directly comparable to Transmogrifiers than Analog Circuitry was. Comparing to Transmogrifiers reveals how much complexity has been added:

    • The function names no longer clue what the functions do.
    • The function outputs are, instead of being directly given, only given by (unordered) definitions and a grid where some letters are double-checked.
    • The function inputs are, instead of being directly given, taken from a large unordered input bank.

    On the other hand, the functions in this puzzle don't have numerical parameters, and (also unlike Analog Circuitry) each single expression involves at most four of them. Despite this, I think overall this puzzle is more complicated/harder than Transmogrifiers. Whether that's a good thing, or whether this puzzle is more complicated/harder than Analog Circuitry, is up to your judgement.
