    Solution to Jumping to Conclusions

    Answer: OMITTED
    Written by: Tim Wong and Dan Simon

    At the beginning of the puzzle, we are presented with a short conversation between a couple of people: they are arranging a testsolve for a meta-matching puzzle, but have unfortunately lost the answer bank. Our task is to solve the metapuzzle despite not having the answer bank. Fortunately, the shells usually provide enough information to shortcut most mini-metas without having any of the feeder answers. Nutrimatic and Qat are two very useful tools for this puzzle.

    A Pure Metapuzzle

    As indicated by the puzzle title, this is a pure mini-meta. As we do not have the feeder answers, this puzzle cannot be solved. Fortunately, the answer to this puzzle is not needed to solve the metapuzzle.

    Bilingual

    We are presented with some blanks and a word bank, written in Pinyin. This suggests that we should fit the words into the blanks. We may try to translate the words from Pinyin to Chinese characters, then back to English, but that can be very difficult due to homophone ambiguity. (For example, "CHUAN" can be 川, 穿, 船...)

    However, as we are given the length of the words and the letters to extract, there are only a couple of possibilities for each extracted letter. We can set up a Nutrimatic query in the form of [dflsx][euaiu][gon][dflsx][ioa][gon][gn][ioa], then use Nutrimatic to find the possible answers. DUOLINGO, one of the top results that is also thematic, is the answer to this mini-meta.

    Chimera

    We are presented with a two-row table with 26 entries. The top rows go from A to Z, and the bottom rows contain a word segment. It seems that we need to arrange these word segments to form words or sentences. If we examine the word segments, we might notice that entry "S", "P" and "H" contain the word segment "AN", "SW", and "ER" respectively, which form the word "ANSWER". "SPH" is a common prefix in English, suggesting that we might want to find a word that starts with "SPH" and use it to extract a sentence. "SPHINX" is a compelling choice, as it is a combination of multiple creatures, which is thematic to both the puzzle and the title.

    Translating "SPHINX" to word segments gives the full phrase "ANSWER TYPHON", so TYPHON is the answer to this mini-meta.

    Dates

    We are given an example, followed by a list of months. The example teaches us how the extraction works in this puzzle: New Year's Day is January 1st, and the first letter of "January" is J. We will also need to do the same for the list of months, possibly via the feeder answers that are not given to us.

    However, we know that the letter extracted must appear in the month (for example, the first letter must come from the word "MARCH"), so we can set up a Nutrimatic query that checks all letters in each month. The top result, CONTEMPORARY, is the answer to this mini-meta.

    Goosebumps

    As suggested by the title and the flavor text, this is a mini-meta about the Goosebumps book series, and the blanks are likely to be books from the original series. As enumerations are given, we can use it to find the books whose titles matches the enumerations.

    Book Title#A1Z26
    Return of the Mummy23W
    Welcome to Camp Nightmare9I
    The Werewolf of Fever Swamp14N
    Monster Blood3C
    The Curse of the Mummy's Tomb5E

    All of these books are early in the order of release. We can convert them to letters via A1Z26 to obtain WINCE, the answer to this mini-meta.

    Skyscrapers

    We are given two skyscrapers. Instead of the regular numbered clues, we are given word clues. To understand how the word clues and extraction work, we can try to solve the smaller example puzzle.

    To solve the puzzle, the word clues need to be converted to its alphabetically-ordered numbering (the letter that appears first alphabetically is 1, the letter that appears second alphabetically is 2, and so on). These numbers indicate the skyscraper buildings along that direction. To extract, we read the topmost skyscraper from top to bottom (as hinted by the answer of the example).

     RUN CAB
     213
     321
     132

    However, in the actual puzzle, the word clues, which is very likely to be from the feeder bank, are not given, so we need to find another way. Luckily, since we know how to extract letters from the grid, we can set up a Nutrimatic query that extracts one letter from each row. The query may look something like this: [whsenak][apcdob][oncldip][fedora][bengali][science][defghi]. We can also use the fact that buildings cannot repeat along a column to reduce the search space, or even write a program to enumerate all possible answers.

    In any case, we can go through the candidates and select those which fits the constraints. A thematic candidate is EDIFICE, which is the answer to this mini-meta.

    Web

    We are given a couple of webs with some circles and arrows. The final image uses golden arrows, and the circles have a gold border as well, so we can assume that this will be the answer for this mini-meta.

    It seems that we need to fill in each circle with a letter such that a word is spelled out for each sequence of arrows. It is likely that each sequence of arrows, except for the final one, corresponds to a feeder answer. Without the feeder bank, however, we need to find a way to guess the letters only from the arrow connections. Qat has an "equation solver" feature that allows us to specify patterns for multiple words, so we can construct a Qat query that contains the letter pattern for all sequences of arrows. (One assumption we made is that all of the answers are single words.)

    Qat gives only one result. We can use it to solve the entire web and extract the answer to this mini-meta, INTERTWINE.

    Metapuzzle

    We have the following mini-meta answers:

    We are given a partially-corrupted shell for the metapuzzle. We only know the index positions of the letters to be extracted, but not the puzzle names. Furthermore, we are missing one mini-meta answer. However, we can still make a key observation from the shell: the sixth letter to be extracted must be from a puzzle whose answer is at least 14 letters long. Since none of our currently mini-meta answers has at least 14 letters, the answer must be from "A Pure Metapuzzle".

    Since we know the rest of the mini-meta answers, we can use Nutrimatic to construct a query that checks all candidate letters for each letter position, except for the sixth letter, which can be any. The query may look something like this: [ooi][nmntc][uoiynd][dcwtie][nmntc]A[uoiynd] .

    Putting this into Nutrimatic one final time gives us OMITTED as the top result, which is the answer to this puzzle.
