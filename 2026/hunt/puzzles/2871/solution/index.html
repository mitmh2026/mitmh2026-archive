    I knew very early that I wanted to write a Celeste puzzle, but we have many team members who like writing video game puzzles, so I was not sure if I wanted to write a Celeste puzzle enough to take one of the limited number of video game puzzles we could have before the hunt felt like it had too many. I had previously considered even more obscure (but more varied) bingo-centric ideas, which I will not go into further in case I use them for a future puzzle.

    After some time revisiting the idea of a Celeste puzzle every so often, I had mostly decided to not write one (with one brief period of changing my mind when I saw DEPTHS was an answer in an overworld meta testsolve, only to learn when solving the meta that it was a red herring answer). However, a few weeks before Alphabet full-round testsolve, it became clear that we needed a few more puzzles; I tried to ideate a no-letter puzzle and this idea came out fairly quickly. The answer REJECT is probably in the bottom 10% of answers for a puzzle about something I really enjoy, but I believe it was the only one remaining at the time that we wanted to assign to a puzzle solvable without letters.

    I am still unsure to what extent this puzzle is a conlang puzzle. I certainly thought of it as one when writing, but I think the language has been made understandable and simple enough that I'm not sure whether it counts, though it does have some quirks. If you want to use this language for anything, feel free to ignore or undo any of the bad decisions I made; I considered adding more notes about aspects of the language not used in the puzzle to this solution, but decided it was better to let people decide for themself in the unlikely event they wanted to use the language.
