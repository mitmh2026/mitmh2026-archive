    Solution to Night Circus

    Answer: THRU
    Written by: Sam Wang

    We are presented with a table, where each row contains a single "codename" and a single rebus. After solving a few rebuses (with the easiest being "Nidoran♂" and "1.054 x 10-34 J⋅s"), we discover that each rebus clues the astronomical symbol for some planet or minor planet. This is reinforced by the flavor text "wandering group's heavenly performance"—note that the word "planet" comes from the Ancient Greek word for "wanderer".

    By examining similarities/differences in the codenames of each of the planets/minor planets, and correlating them with the relationships between the planets/minor planets, we can deduce the meanings of each ASCII symbol in each "codename". With the exception of the number in parentheses, there are 6 ASCII symbols in each "codename":

    • The 1st ASCII symbol is the initial of the first spacecraft to flyby that planet/minor planet. A number is placed in parentheses after this initial if there is a number in the spacecraft. For example, P(10) represents Pioneer 10. Planets/minor planets without a spacecraft flyby are represented with a "-" instead.
    • The 2nd ASCII symbol is the length (i.e. number of digits) of the IAU number. Planets don't have IAU numbers and are represented with a "-" instead.
    • The 3rd and 4th ASCII symbols together represent the name origin of the planet/minor planet. The 3rd symbol is an initial for the name origin's culture, and the 4th symbol is an initial for the name origin's entity type. For example, "RG" represents a "Roman God", and "GM" represents a "Greek Muse".
    • The 5th and 6th ASCII symbols together represent the two-letter country code of the modern-day country containing the planet/minor planet's discovery site. Planets that could be seen with the naked eye were discovered independently by multiple ancient cultures, and therefore do not have a discovery site (represents with a "-" instead).
