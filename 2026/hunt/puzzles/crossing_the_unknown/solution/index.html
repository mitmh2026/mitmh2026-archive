    Solution to Crossing the Unknown

    Answer: SOMEWHAT OVERDONE
    Written by: Kevin Der
    Edited by: Herman Chau
    Additional thanks to:
    • Peter Vera for implementation

    Overview

    This is a crossword puzzle where each tile is used in both a horizontal entry and an additional entry that is either diagonal or a snake-like shape. The starting tile for each entry has crossword clues associated with them. The horizontal and diagonal entries have their directions indicated, however the snake entries require the solver to determine the path of tiles that comprise the answer. For any correct answer to a snake entry, however, there is always one unique path spelling out that answer beginning with the first tile.

    Levels

    Level: Orientation

    This is what solvers see when they first unlock the round. The tile bank contains only letters. Aside from serving as an introduction to tile placement in general, it also has several special clues designed to teach about the round and this particular puzzle, which are shown below in bold.

    Level: Valuation

    For this level the tile bank contains various playing cards in addition to letters. The solver must realize that a number of these cards must appear in a sequence; the entry passing through them will interpret all the cards as the name of a corresponding poker hand. The other entry using each of the above cards will either interpret the card as a suit or a value. For example, the K♥️ becomes KING in the answer PEEKING, and the 7♥️ becomes HEART in THE ARTIST, but both appear in a sequence of 5 cards that is a FLUSH.

    At times, the poker hand will dictate either the suit or value of each card, but there may be multiple cards in the tile bank that satisfy those constraints. In these cases, logical deduction allows for determining the unique card to place in each location.

    Extraction

    The snake crossword clues for the final level also contain numbers that are crossed out in red. After identifying the snake paths, cross out the tiles in that path corresponding to those numbers. The remaining letters spell the answer, SOMEWHAT OVERDONE.
