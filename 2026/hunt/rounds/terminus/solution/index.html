    Solution to Terminus

    This solution explains how to unlock puzzles in this round. For how the meta works, see the meta solution instead.

    All of the puzzles in this round, with the exception of the round metapuzzle, are discovered by making the appropriate input in the terminal on the round page. After they are discovered once, they are permanently accessible. The round is split into six different sets of puzzles, each of which contains its own metapuzzle.

    Each input is determined to either be illegal, returning the error message "Nothing was found in this universe." or an input that is of one of six types, corresponding to the six regions on the round page. From left to right, these are as follows:

    Input TypeLegal valuesUnlocked Puzzle Series
    NumberA non-negative integerDichotomies
    ColorSix hexadecimal characters [0-9A-Fa-f], with at least one digit and letterRGBA
    DateX/Y/Z, where X, Y, and Z are numbers (read as year/month/day)Trends
    SentenceA string containing only spaces and letters, with at least one spaceLayers
    EmojiA single emojiPsychology
    WordA string containing only lettersCan you really call it a crossword if...

    Each input is then converted into each of the other five types, according to a conversion rule. Each of the six inputs then gives some puzzles, or an error message, based on a specific rule for each input type. For puzzle unlocking purposes, a converted input of the same value works exactly the same as a "native" input.

    We expect that most solvers will approach this round by first trying a wide variety of possible inputs. After determining some rules about how some of the input types work, most solvers will likely focus on a specific input type, aiming to test theories about how its unlocking works. However, occasionally (and especially early in the solving process) they will still uncover a new puzzle or interesting error message for a different input type, so there is some benefit to understanding the conversions, as they can allow solvers to gain additional information from previous converted inputs.

    After solving each region's metapuzzle, the round page shows the value after conversion, which should help to confirm any theories about how the conversion works. The conversions are intended to be reversible, so that applying the conversion from type A to B, and then the conversion from type B to A generally returns the original value in one direction, and the original value with some information loss in the other direction. The full table of conversion rules are as follows:

    Input TypeOutput TypeMechanism
    NumberColorConvert to hexadecimal and then to color (padding with initial zeros/only using first six chars)
    NumberDateUse input as year (take x/1/1)
    NumberSentenceFull name of number, written out in words
    NumberEmojiConvert to hexadecimal and then take emoji with that codepoint
    NumberWordConvert to "base 26" with digits A = 0, ..., Z = 25 (no leading zeros)
    ColorNumberConvert color code from hexadecimal
    ColorDateWrite out each digit of color code as hex, concat, [all but last 4 digits]/[last 4th and 3rd]/[last 2nd and 1st]
    ColorSentenceName of closest named color (by taxicab distance in RGB space)
    ColorEmojiStrip initial zeros from hex code and then take emoji with that codepoint
    ColorWordConvert each digit of color code to letter with 0 = A, ..., F = P
    DateNumberTake (year / month) / day (conversion fails if not an integer)
    DateColorConcatenate year, month, and day, greedily parse as hex digits (do not pad/cut, no puzzle if not six chars)
    DateSentenceFull name of date, written out in words (including writing numbers in date as words)
    DateEmojiConcatenate year, month, and day, parse as number, convert to base 16, take emoji with that codepoint
    DateWordConcatenate year, month, and day, greedily parse as letters with 0 = A, ..., 25 = Z
    SentenceNumberIf sentence is a name of a number, return that number, otherwise conversion fails
    SentenceColorColor with closest name under Levenshtein distance
    SentenceDateIf sentence is a name of a date, return that date, otherwise conversion fails
    SentenceEmojiEmoji with closest name under Levenshtein distance
    SentenceWordRemove spaces
    EmojiNumberConvert codepoint from hexadecimal
    EmojiColorConvert codepoint to color (padding with initial zeros/only using first six chars)
    EmojiDateConvert codepoint from hexadecimal, then use as year (take [year]/1/1)
    EmojiSentenceName of emoji
    EmojiWordConvert each digit of codepoint to letter with 0 = A, ..., F = P
    WordNumberConvert from "base 26" with digits A = 0, ..., Z = 25 (leading A's ignored)
    WordColorConvert each character to a hex digit via A = 0, ..., P = F, Q = 0, ..., Z = 9
    WordDateConvert from "base 26" as with Word to Number, then use result as year as with Emoji to Date
    WordSentenceAdd a space between every pair of letters (so each letter becomes its own word)
    WordEmojiConvert each character to a hex digit as with Word to Color, then take emoji with that codepoint

    Taking an emoji with a codepoint strips initial zeros where relevant, and causes conversion to fail if there is no such emoji. Multi-codepoint emoji, for purposes of conversion, are considered to have a codepoint that is the concatenation of the individual codepoints. For example, 🏳️‍🌈 is considered to have codepoint 1F3F3FE0F200D1F308.

    In greedy parsing (used for Date to Color and Date to Word), the first two digits are taken if they are under the relevant bound (16/26), otherwise one digit is taken, and then the process repeats. For example, 12/17/2025 is parsed as hex as 12, 1, 7, 2, 02, 5, or C17225.

    In each region, the metapuzzle is unlocked by an input associated with all of the rules that unlock the regular puzzles in the region.

    We can now consider the specific rules for unlocking each of the puzzles in the six regions.

    Number

    Inputting 0 gives an error, "Number is zero". This, along with some experimentation, may lead solvers to deduce that this region is about prime factors.

    Each of the puzzles is associated with a small prime number:

    PuzzlePrime
    RB2
    RGC3
    CS7
    CWT17
    LM61

    Any input containing one of these primes as a factor gives the corresponding puzzle. The metapuzzle is unlocked with the input 43554, the product of these primes. Note that multiples of 43554 will unlock all of the puzzles at once, but not the metapuzzle.

    Color

    Any valid color will give some puzzle (in most cases, only one); solvers should start to derive the unlock mechanism from noticing that colors that are "close" (i.e. have small RGB differences) usually give the same puzzle.

    The puzzle given is based on vague direction from the metapuzzle color; this can be computed by looking at the red, blue, and green difference from the metapuzzle color (input value - metapuzzle color value), and looking at which of the following four values is maximum. In the below table, these differences are called RD, GD, and BD.

    PuzzleMaximum?Color in vague maximum direction
    AlphaRD + GD + BDWhite
    RedRD - GD - BDRed
    Green-RD + GD - BDGreen
    Blue-RD - GD + BDBlue

    As can be seen from this, red/green/blue are in the directions corresponding to their puzzles.

    If multiple of the above values are all the maximum, then the corresponding puzzles will all appear (e.g., for RD = 1, GD = 0, BD = 0, both RD + GD + BD and RD - GD - BD will be 1 and both Alpha and Red will appear). There are two-dimensional subspaces of the color space where two puzzles appear, and one-dimensional subspaces where three puzzles appear. In practice, the metapuzzle color is easiest to find by finding the spaces with two puzzles and then within them the spaces with three puzzles, rather than by reverse-engineering the exact mechanism. The metapuzzle is unlocked with ADA548.

    Date

    This puzzle has various errors mentioning Y/M/D and also an error "too far in the future" (for years from 10000 onwards), which may suggest it corresponds to dates. This puzzle uses fairly intuitive date conditions, which are fairly clear once solvers determine this puzzle corresponds to dates; however, solvers will often unlock some parts of this puzzle by inputting numbers rather than dates, which does not allow for accessing some of the puzzles and makes one of the unlock conditions less intuitive.

    The puzzles given are based on the following date properties (more than one can be given at the same time):

    PuzzleThing checkedRequired value
    FoodsYear thousands place2
    NamesYear hundreds place0
    FinanceYear tens place6
    WordsYear ones place9
    EventsMonthMarch
    SportsDay of month3
    NumbersDay of weekSunday

    Note that the first three conditions almost correspond to millennium/century/decade, but to make behavior more intuitive for solvers years ending in 3 or 2 zeros are considered to be the start of the "millennium"/"century", not the end; for example, any day in 2000 will unlock the Foods and Names puzzles. Note also that, both for checking if the input is a valid date and for computing day of week, this puzzle uses the proleptic Gregorian calendar, not the Julian calendar. The only day (within the range of 1-9999) that satisfies all these conditions is 2069/3/3, which unlocks the metapuzzle.

    Sentence

    Most inputs will give the error message "Sentence is not in poem", which tells us that we need to find strings that are contained in some target poem.

    The simplest way to do this is to realize that inputs for this section don't need to be words, and it's sufficient for the input to be a substring of the poem, rather than containing full words from the poem. Thus, starting with an extremely common string like "E S", and trying possible continuations to add a letter at a time to the input is sufficient to unlock the sub-puzzles.

    The sub-puzzle unlocked corresponds to the number of words in the input:

    PuzzleNumber of Words
    Colored2
    Rounded3
    Bordered4
    Bowled5
    Trapezoidal6+

    After uncovering a few words, solvers can use them to determine that the poem in question is Ralph Waldo Emerson's Terminus, a thematic choice for this round.

    Inputting the entire text of the poem gives the metapuzzle for this region.

    Emoji

    Puzzles in this round are unlocked according to the visual properties of the input emoji. The input field forces the emoji to display as a twemoji, and the twemoji version of the emoji is used to determine whether it satisfies each of the conditions (this is relevant, since some other implementations of emojis use different colors). The conditions correspond to fairly common conditions for emojis to satisfy, so solvers should be able to gather data to deduce the conditions fairly quickly.

    The conditions and corresponding puzzle unlocks are as follows:

    PuzzleCondition
    EmotionHas Orange
    IntelligenceHas Non-human Animal
    PerceptionHas Feet/Legs
    PersonalityHas Hands/Arms

    The metapuzzle is unlocked by the one twemoji that has all of these properties, the Orangutan 🦧.

    Word

    Inputting a string that isn't a common word will give the error message "Word not in dictionary". After experimenting, solvers will find that words containing many letters seem to unlock many puzzles. This suggests a condition involving what letters the input contains. One puzzle is unlocked by any five letter input.

    PuzzleCondition
    no crossesHas C
    no fillHas O
    no diagramHas R
    no wordsHas S
    no gridsHas W
    no cluesFive Letters

    The metapuzzle is unlocked with a common five-letter word containing the letters C, O, R, S, and W: CROWS.
